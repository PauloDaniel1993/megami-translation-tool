Megami Translation Workflow Commands

1. Build Structured Corpus

Creates decoded inspection text, structured display pages, scenes, batches, and an HTML preview.

python tools/build_corpus.py --file s1.adx

Outputs:

work/decoded_adx/s1.txt
work/corpus/s1.scenes.json
work/corpus/s1.pages.jsonl
work/corpus/s1.batches.jsonl
qa/reports/s1_corpus_preview.html

2. Preview DeepSeek Summary Prompts

Dry run only; does not call the API or write production summary files.

python tools/summarize_scenes.py --file s1.adx --limit-scenes 1 --dry-run

Output:

qa/reports/s1_summary_prompts.jsonl

3. Generate Scene Summaries

Requires a DeepSeek API key in the environment.

$env:DEEPSEEK_API_KEY = "your-key-here"
python tools/summarize_scenes.py --file s1.adx --model deepseek-v4-flash

Outputs:

translations/context/chunk_summaries/s1.chunks.jsonl
translations/context/scene_summaries/s1.scenes.json

4. Preview Translation Prompt

Dry run only; creates a prompt report for inspection.

python tools/translate_batches.py --file s1.adx --limit 1 --dry-run

Output:

qa/reports/s1_translation_prompts.jsonl

5. Translate Draft Batches In Parallel

Runs DeepSeek on a limited number of medium batches. Results are written as one JSON file per batch so parallel writes are safe and resumable.

python tools/translate_batches.py --file s1.adx --limit 5 --model deepseek-v4-flash --concurrency 3

Output:

translations/drafts/s1.deepseek-v4-flash/
  s1_batch_0001.json
  s1_batch_0002.json
  ...

6. Merge Draft Batches

Merges per-batch JSON files into JSONL for table parsing, validation, and review.

python tools/merge_translation_batches.py --input-dir translations/drafts/s1.deepseek-v4-flash --output translations/drafts/s1.deepseek-v4-flash.jsonl

7. Validate Drafts

Checks line IDs, CP932 encoding, 50-character line limit, and accidental Japanese text.

python tools/validate_translations.py --file s1.adx --translations translations/drafts/s1.deepseek-v4-flash.jsonl

Outputs:

qa/reports/s1_validation.json
qa/reports/s1_validation.html

8. Repair Failed Draft Lines

If validation reports overlong lines or CP932 punctuation problems, generate targeted repairs instead of retranslating every batch.

python tools/repair_translations.py --file s1.adx --translations translations/drafts/s1.deepseek-v4-flash.jsonl --validation-report qa/reports/s1_validation.json --output translations/repairs/s1.length_repairs.jsonl --model deepseek-v4-flash --concurrency 3

Apply the repair output over the base draft JSONL:

python tools/apply_translation_repairs.py --base translations/drafts/s1.deepseek-v4-flash.jsonl --repairs translations/repairs/s1.length_repairs.jsonl --output translations/drafts/s1.deepseek-v4-flash.repaired.jsonl

Validate the repaired file:

python tools/validate_translations.py --file s1.adx --translations translations/drafts/s1.deepseek-v4-flash.repaired.jsonl

9. Approve Translations

Copy reviewed batch records into translations/approved/s1.approved.jsonl. Approved records should keep the same batch_id and translations shape.

10. Build Patch Jobs

Creates patch jobs for approved lines and optional glossary-controlled speaker names.

python tools/build_patch_jobs_from_translations.py --file s1.adx --translations translations/approved/s1.approved.jsonl --jobs patch_jobs/s1_translated_jobs.json --include-auto-speakers

11. Reinsert

Uses the existing game management script to patch clean original ADX files.

python tools/game_management.py reinsert --file s1.adx --jobs patch_jobs/s1_translated_jobs.json --out-dir patched_adx

Notes

  • Do not edit files under work/; regenerate them.
  • Human-reviewed translation state belongs under translations/approved/ or translations/manual_overrides/.
  • Dry-run commands only write prompt reports under qa/reports/.
  • Use --limit for small tests before running full-file translation.
